# Name patterns for the main blacklist.
#
# One extended regular expression (grep -E syntax) per line; lines are joined
# with "|" and matched case-insensitively against:
#   data/all-ru-asn.txt, data/all-ru-ipv4.txt, data/all-ru-ipv6.txt
#     "<ASN|prefix> <as-name|netname> (<org-name>)"
#   data/ripe-ru-ipv4.txt
#     "<prefix> <netname> <mnt-by...> (<org handle>) [<descr>]"
# Matching entries are blacklisted unless they also match white-names.txt.
# Matching ASNs contribute all prefixes they announce in BGP.
#
# Empty lines and lines starting with "#" are ignored.
